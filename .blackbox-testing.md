# Pengujian Black Box — Sistem Absensi Siswa SD Inpres Tamamaung IV

Dokumen ini berisi rancangan pengujian **black box** (uji perilaku fungsional tanpa melihat kode internal)
untuk seluruh halaman dan fitur aplikasi. Teknik yang digunakan:

- **Equivalence Partitioning** — mengelompokkan input valid/invalid.
- **Boundary Value Analysis** — menguji nilai batas.
- **State Transition** — perubahan status (scan ulang, role, status siswa).
- **Error Guessing** — menebak kemungkinan kesalahan (input kosong, duplikat, akses tak diotorisasi).

## 1. Ringkasan

| Area | Halaman | Kategori |
|------|---------|----------|
| Autentikasi | Login, Logout | Input |
| Scan | Scan Mandiri, Scan Internal | Input |
| Entri Data | Tambah/Edit Siswa, Absensi Manual, Pengaturan Jam | Input |
| Master | Data Siswa, Data Kelas, Data Pengguna | Output |
| Cetak | Barcode/QR Siswa, Kartu Barcode Saya | Output |
| Laporan | Dashboard, Laporan Absensi, Riwayat Saya | Output |

## 3. Catatan Pelaksanaan

- Jalankan dengan `php artisan test` untuk tes otomatis; uji manual memakai browser (Chrome desktop + mobile).
- Gunakan database terpisah (SQLite `:memory:` untuk otomatis, atau clone MySQL untuk manual).
- Data uji dibuat via seeder (kelas → wali → siswa → akun siswa → absensi).
- Prioritaskan: **BB-11 s/d BB-19** (alur inti absensi), **BB-01 s/d BB-11** (auth & role), baru modul lain.
