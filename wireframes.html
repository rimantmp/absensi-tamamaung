Wireframe — Sistem Absensi Siswa

SD Inpres Tamamaung IV · Aplikasi absensi berbasis QR/barcode. Stack: Laravel (Blade) + Tailwind CSS + MySQL. Dokumen ini memetakan seluruh halaman yang benar-benar ada pada project (berdasarkan routes/web.php dan folder resources/views) dalam bentuk wireframe hitam-putih yang konsisten.

1b. Klasifikasi Halaman — Input & Output

Pembagian seluruh halaman ke dalam dua kategori berdasarkan fungsi utamanya: Input = halaman yang menerima entri data dari pengguna (form / scan); Output = halaman yang menyajikan data (daftar, ringkasan, kartu cetak, ekspor).

Seluruh halaman dibangun dari komponen berikut. Halaman 01–02 memakai Public Layout; halaman 03–14 memakai App Layout.

Layout A — Public (dipusatkan)

Header ikon sekolah + judul + subtitle di tengah, area konten maks 720px, tombol aksi di kanan-atas. Di mobile: aksi turun ke bawah header.

Layout B — App (sidebar tetap)

Brand + tombol Quick Scan + menu navigasi (sesuai role) + footer (Scan Mandiri, info user, Logout). Page-head judul/subtitle + actions. Mobile (≤900px): sidebar menjadi bar atas horizontal.
