## Status Akhir

## Ringkasan Awal

Dari 27 test black box yang dibuat di `tests/Feature/BlackBoxTest.php`, 3 test gagal saat pertama kali dijalankan. Setelah penelusuran, kegagalan tersebut **bukan bug aplikasi**, melainkan kombinasi kesalahan logika test dan bug internal Laravel yang menutupi pesan error asli.

## Akar Masalah

### 1. Bug internal Laravel: `Call to a member function all() on array`

Saat sebuah assertion gagal pada respons yang menggunakan session driver `array`, Laravel memanggil `Illuminate\Testing\TestResponseAssert::injectResponseContext()` yang mengakses `$response->getSession()->all()`. Karena session-nya berupa array, pemanggilan `->all()` pada array memicu `Error` sehingga pesan kegagalan assertion asli **tertutup** oleh error ini.

### 2. Kesalahan logika pada 3 test

| Test | Kesalahan | Perbaikan |
|------|-----------|-----------|
| `test_blackbox_siswa_login_diarahkan_ke_riwayat` | Login memakai username statis `'siswa'` padahal `makeRoleUser('Siswa')` membuat username acak (`siswa###`), sehingga login gagal dan redirect tidak mengarah ke riwayat. `assertRedirect` juga tidak mengikuti redirect. | Login memakai `$user->username`; assert redirect ke `/dashboard`, lalu ikuti ke `student.history`. |
| `test_blackbox_scan_barcode_kosong_ditolak` | Mengharap status 422, padahal aplikasi mengembalikan 302 (redirect validation). Ini perilaku wajar: JS `fetch` tanpa header `Accept: application/json`, sehingga `$request->validate()` melempar redirect, bukan JSON 422. | Assert status 302 + pastikan tidak ada baris `Attendance` baru tercatat. |
| `test_blackbox_guru_laporan_hanya_kelas_walinya` | `assertDontSee('Siswa Bukan Saya')` gagal karena dropdown filter siswa menampilkan seluruh siswa, meski tabel laporan sudah benar hanya berisi siswa kelas wali. | Asersi dipersempit ke sel tabel (`>Siswa Bukan Saya</td>` tidak boleh muncul) supaya presisi dan tidak terganggu konten dropdown. |

## Catatan

- Dropdown **filter siswa** di halaman laporan masih menampilkan semua nama siswa (kebocoran nama di UI filter), meskipun **data absensi di tabel** sudah tersaring sesuai kelas wali. Ini bukan kebocoran data absensi, hanya tampilan daftar pilihan.
- `tests/Feature/DebugTraceTest.php` dibuat sementara untuk menelusuri akar masalah dan telah dihapus setelah selesai.
